# AgentBenchBench

A meta-benchmarking framework for evaluating and comparing AI agent benchmarks and evaluation suites.

## Overview

AgentBenchBench is designed to benchmark, analyze, and compare the effectiveness, reliability, and coverage of various AI agent benchmarks.

## Features

- **Meta-Evaluation**: Compare benchmark characteristics, difficulty curves, and discriminative power.
- **Reproducibility**: Standardized interfaces and execution environments for running and comparing multiple agent benchmarks.
- **Analytics & Metrics**: Comprehensive metrics on benchmark robustness, agent saturation, and evaluation cost.

## Getting Started

### Prerequisites

- Python 3.10+
- Git

### Installation

```bash
git clone https://github.com/ericfzhu/AgentBenchBench.git
cd AgentBenchBench
```
